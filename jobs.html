Frontend Developer

Ref Number: FE102

We are seeking a dedicated Frontend Developer to design and deliver high-performance web applications, patient management portals, and responsive digital health interfaces.

Salary Range: $85,000 - $105,000 AUD per annum

Reporting Line: Reports directly to the Lead Frontend Engineer

Key Responsibilities

  1. Develop responsive, cross-browser web components using HTML5, CSS3, and JavaScript.
  2. Collaborate closely with UI/UX designers to translate wireframes into clean, functional interfaces.
  3. Optimize applications for maximum speed, performance, and WCAG accessibility standards.
  4. Integrate secure RESTful APIs to communicate with backend appointment and health data systems.

Requirements

Essential Requirements:

  • Bachelor's degree in Computer Science, Software Engineering, or equivalent practical experience.
  • Minimum 3 years of hands-on experience in modern frontend web development.
  • Strong competency in HTML5, CSS3, semantic web design, and responsive layouts.

Preferable Requirements:

  • Experience building web applications within the healthcare or medical industry.
  • Familiarity with web accessibility compliance (WCAG 2.1 AA guidelines).

  • Proficiency in standard UI design tools such as Figma, Adobe XD, or Sketch.

Preferable Requirements:

  • Understanding of frontend web development constraints (HTML/CSS).
  • Prior experience designing patient portals or clinical dashboard tools.

Backend Developer

Ref Number: BE306

Develop robust server architecture, secure database infrastructures, and reliable APIs supporting appointments and patient record platforms.

Salary Range: $90,000 - $120,000 AUD per annum

Reporting Line: Reports directly to the Engineering Director

Key Responsibilities

  1. Design, build, and maintain scalable server-side applications and microservices.
  2. Ensure data security, regulatory compliance, and encryption standards for patient health records.
  3. Build and optimize RESTful or GraphQL APIs for frontend application integration.
  4. Monitor system uptime, handle database tuning, and troubleshoot server performance bottlenecks.

Requirements

Essential Requirements:

  • Degree in Software Engineering, Computer Science, or related technical field.
  • Minimum 3+ years backend engineering experience with Node.js, Python, or Java.
  • Extensive experience working with relational databases (PostgreSQL, MySQL) and NoSQL stores.

Preferable Requirements:

  • Experience with HIPAA, GDPR, or Australian healthcare data security compliance.
  • Familiarity with cloud deployment platforms like AWS, Azure, or Google Cloud.

QA Tester

Ref Number: QA612

Perform rigorous functional, integration, and security testing across our digital healthcare applications to ensure uncompromised quality and reliability.

Salary Range: $75,000 - $92,000 AUD per annum

Reporting Line: Reports directly to the QA Lead / Test Manager

  2. Execute manual and automated test scripts across web and mobile health applications.

  • Familiarity with software QA methodologies, test case design, and bug lifecycle tracking.
  • Strong analytical mindset with keen attention to detail.

Preferable Requirements:

  • Experience with automated testing frameworks (Selenium, Cypress, or Jest).
  • ISTQB Foundation Level certification in Software Testing.
